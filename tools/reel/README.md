# 시범 공연 릴스 편집 도구 (격파·발차기 순간 정밀 편집)

국가대표 용인대 태권도 아리랑 시범단 야외 시범 영상 → 케이팝 뮤직비디오 스타일 1080x1920 릴스.
필요한 것: ffmpeg, python3 + numpy, 한글 굵은 글꼴(NotoSansCJK-Bold).

## 작업 순서
1. **소리 피크 찾기**: `python3 onsets.py "영상 원본/야외 시범/"*.mp4 -o work/onsets.csv`
   - 격파음·타격음(transient), 기합·함성(sustained)을 모두 후보로 뽑는다.
2. **초당 10장 확인표**: `python3 sheets.py work/onsets.csv -d work/sheets`
   - 후보마다 앞뒤 1초(0.1초 간격 21칸) 확인표를 만든다. 0번 칸이 빨간 테두리.
   - 송판이 실제로 깨지는 칸, 발이 실제로 닿는 칸만 고른다. 확실하지 않으면 **뺀다**.
   - 고른 칸의 원본 시각을 edl.json의 `impact`에 적는다.
     필요하면 `sheets.py --file 원본.mp4 --at 시각`으로 다시 확대해 확인한다.
3. **편집**: `python3 render.py edl.json` (예시: edl.example.json)
   - impact 장면 = 깨지기 직전부터 시작(정상 속도) → 깨지는 순간 느린 화면(기본 0.35배)
     + 확대 + 화면 번쩍임 + 짧은 흔들림 → 직후 정상 속도.
   - 느린 화면은 프레임을 섞지 않는다(섞으면 깨지기 전 칸에 깨진 모습이 비친다).
   - 색보정: 대비·채도 강화, 시원한 그림자/따뜻한 하이라이트, 비네팅. 음량은 -14 LUFS로 맞춘다.
4. **완성본 재검증**: `python3 verify.py 완성본.mp4 -d work/verify`
   - 전체를 0.5초 간격으로 훑는 개요표 + 격파 순간마다 초당 10장 확인표.
   - 격파 순간이 아닌 장면이 있으면 edl.json을 고치고 3단계를 다시 돌린다.
5. `완성본_report.md`에 "완성본 몇 초 ← 원본 몇 초" 표가 자동으로 만들어진다.
