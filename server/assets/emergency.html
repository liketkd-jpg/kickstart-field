KICKSTART UP 현장 모드 · 진행 요원용
코트마다 한 장씩 붙여 두세요
먼저 이것부터: 당황하지 말고 경기를 잠시 멈춘 뒤 본부에 알립니다. 점수와 결과는 노트북에 계속 저장되고, 1분마다 본부에도 모이므로 대부분 그대로 이어서 진행할 수 있습니다.

1코트 노트북이 꺼졌어요

  1. 전원을 연결하고 노트북을 다시 켭니다.
  2. 바탕화면의 현장 프로그램(검은 창)을 실행합니다.
  3. 첫 화면에서 같은 코트(A~E)를 고르고 운영석 열기.
  4. 멈췄던 경기부터 그대로 이어집니다. 심판 태블릿은 1분 안에 저절로 다시 연결됩니다.

2코트 노트북이 고장 났어요 (예비 노트북으로)

  1. 예비 노트북에서 현장 프로그램 실행 → 첫 화면에서 고장 난 코트를 고릅니다.
  2. 코트 화면 아래 🛟 본부에서 이 코트 백업 받기를 누릅니다.
  3. 종목 운영석 → 대회 설정 → 백업과 복구의 백업 파일에서 복구에서 받은 파일을 고르고 복구 실행.
  4. 심판은 QR 코드를 다시 찍습니다.
본부에 모인 마지막 백업(1분 간격) 이후의 점수는 다시 입력해야 할 수 있습니다.

3심판 태블릿이 끊겼어요

  1. 태블릿 와이파이가 대회 공유기에 연결돼 있는지 확인합니다.
  2. 채점 화면을 아래로 당겨 새로 고침합니다.
  3. 그래도 안 되면 운영석 📱 QR 접속의 그 심판 번호 QR을 다시 찍습니다.
  4. 1분 넘게 안 되면 예비 태블릿으로 같은 QR을 찍습니다.

4태블릿 배터리가 부족해요

  1. 본부 화면 맨 위 🔋 배지가 빨갛게 깜빡이면, 눌러서 몇 코트 몇 심인지 확인합니다.
  2. 부문과 부문 사이에 충전기를 꽂거나 예비 태블릿으로 바꿉니다 (같은 QR).
  3. 20% 아래는 경기 중에 꺼질 수 있으니 바로 바꿉니다.

5와이파이(공유기)가 끊겼어요

  1. 공유기 전원과 랜선을 확인하고, 꺼졌으면 다시 켭니다 (2~3분).
  2. 노트북마다 점수는 계속 저장되므로 기다렸다가 이어서 하면 됩니다.
  3. 공유기가 살아나면 심판 태블릿·본부 연결은 저절로 돌아옵니다.

6한 코트가 너무 밀려요 (코트 옮기기)

  1. 본부 → 🔀 코트 진행·옮기기.
  2. 추천대로 옮기기를 누르면 남은 부문을 빈 코트로 보냅니다.
  3. 방송으로 선수·지도자에게 코트 변경을 알립니다.
  4. 잘못 옮겼으면 같은 화면의 옮기기 취소.

7상장이 안 나와요

  1. 프린터 전원·용지·토너를 확인합니다.
  2. 본부 ✅ 시작 전 점검에서 프린터가 초록불인지 봅니다 (오프라인·대기 문서 수 표시).
  3. 윈도우 설정 → 프린터에서 멈춘 대기 문서를 취소한 뒤, 본부 🖨️ 상장 자동 출력에서 다시 인쇄합니다.

8방송(호출)이 안 들려요

  1. 본부 노트북 소리와 스피커 연결·볼륨을 확인합니다.
  2. 본부 → 📣 호출·방송에서 소리가 켜져 있는지, 방송 창이 열려 있는지 봅니다.
  3. 급하면 방송 문구를 마이크로 직접 읽습니다.

9노트북 하드가 꽉 찼어요

첫 화면 위쪽 💾 남은 공간을 누르면 하드를 차지하는 곳이 크기순으로 나옵니다. 현장 프로그램 쪽이면 🧹 상장 파일 지우기, 인쇄 대기열이면 설정 → 프린터에서 대기 문서 취소, 임시 파일·브라우저 캐시면 윈도우 설정 → 시스템 → 저장소에서 정리합니다. 대회 전날 3GB 이상 비워 두세요.
