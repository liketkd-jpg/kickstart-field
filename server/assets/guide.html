현장 모드 사용 설명서

인터넷이 없는 경기장에서 노트북 한 대와 공유기로 대회를 운영하는 방법

어떻게 돌아가나요?

💻 노트북 = 본부현장 모드 프로그램을 켜면 노트북이 점수를 모으고 저장합니다.
📶 공유기 = 연결인터넷 선이 없어도 됩니다. 와이파이만 켜지면 기기끼리 연결됩니다.
📱 심판·전광판같은 와이파이에 연결하고 QR을 찍으면 끝. 앱 설치가 필요 없습니다.
인터넷은 프로그램을 받을 때만 필요합니다. 대회 중에는 인터넷이 전혀 없어도 됩니다.

1준비물

  • 윈도우 노트북 1대 (보통 노트북이면 충분합니다) + 충전기
  • 와이파이 공유기 1대 (예: ipTIME AX3000 계열) + 전원 · 가능하면 높은 곳에 올릴 스탠드
  • 심판 휴대폰, 전광판용 노트북·TV 연결 PC (크롬 브라우저)
공유기는 코트들 한가운데, 사람 머리보다 높은 곳에 두면 끝쪽 코트까지 잘 잡힙니다.

2처음 한 번: 설치

  1. 받은 KICKSTART_현장모드.zip을 마우스 오른쪽 클릭 → 압축 풀기. (바탕화면 등 찾기 쉬운 곳)
  2. 풀린 폴더에서 방화벽_허용.bat을 더블클릭 → "예"를 누릅니다.
    휴대폰이 노트북에 접속할 수 있게 윈도우 방화벽을 열어 줍니다. 한 번만 하면 됩니다.
  3. KICKSTART 현장모드.exe를 더블클릭합니다.
"Windows의 PC 보호" 파란 창이 뜨면 → 추가 정보 → 실행을 누르세요. (직접 만든 프로그램이라 처음 한 번 뜨는 안내입니다)
"Windows 보안 경고 · 액세스 허용" 창이 뜨면 개인 네트워크와 공용 네트워크 모두 체크 후 액세스 허용을 누르세요.

3대회 당일 순서

  1. 공유기 전원을 켭니다. (인터넷 선은 꽂지 않아도 됩니다)
  2. 노트북을 그 공유기 와이파이에 연결합니다.
  3. KICKSTART 현장모드.exe를 더블클릭 → 검은 창이 뜨고 크롬이 열립니다.
  4. 열린 화면에서 품새 대회를 누르면 운영석입니다.
  5. 심판 휴대폰을 같은 와이파이에 연결 → 운영석의 📱 QR 접속을 카메라로 찍습니다. 1심은 1심 QR, 2심은 2심 QR…
  6. 전광판 화면도 같은 방법으로 전광판 QR을 엽니다. (또는 주소를 크롬에 입력)
🎵 자유 품새 · 태권체조 · 팀 경연 음원 지도자가 접수 홈페이지에 올린 음원은 「🌐 접수 홈페이지에서 가져오기」로 명단을 가져올 때 이 노트북에 함께 담기고, 팀(선수) 이름으로 자동 연결됩니다. 명단을 본부에서 와이파이로 받은 코트 노트북은 음악 칸의 「🌐 접수 홈페이지 음원 받기」(인터넷 필요)를 누르거나, 본부가 홈페이지에서 내려받은 음원 zip을 풀어 「📁 음악 폴더 고르기」로 넣어 주세요.
🎨 품새 전광판 디자인 고르기 대회 설정의 「전광판 디자인」(또는 운영석 진행 화면·전광판 왼쪽 위의 🎨 칸)에서 기본 금빛 · 매거진 · 시계 · 데이터 · 한지와 먹 · 스트리트 · 클래식 중 하나를 고릅니다. 컷오프(경기 중 → 점수 → 순위표)와 토너먼트(청·홍 → 판정 → 대진표 → 우승 발표)에 모두 적용됩니다. 본부 모니터는 「코트 전광판 따라가기」로 두면 같은 디자인이 됩니다.
검은 창을 닫으면 현장 모드가 멈춥니다. 대회가 끝날 때까지 열어 두고, 노트북 충전기를 꽂아 두세요.

★여러 코트 + 본부로 운영하기

💻 코트 노트북 (A·B·C…)코트마다 한 대. 그 코트의 경기를 운영하고 심판 휴대폰이 접속합니다.
🖥 본부 노트북코트들을 자동으로 찾아 선수 대기실 큰 화면(본부 모니터)에 진행 상황을 띄웁니다.
📶 공유기 하나모든 노트북·휴대폰을 같은 공유기 와이파이에 연결합니다.
  1. 같은 zip을 노트북마다 복사해 압축을 풀고, 노트북마다 방화벽_허용.bat을 한 번 실행합니다.
  2. 각 노트북에서 KICKSTART 현장모드.exe를 켜면 첫 화면에서 역할을 고릅니다: 코트 노트북은 A코트·B코트·C코트, 본부 노트북은 본부. (한 번 고르면 기억합니다)
  3. 코트 노트북은 종목(품새·격파·겨루기)의 운영석을 열어 둡니다. 운영석이 열려 있어야 진행 상황이 본부로 갑니다.
  4. 본부 노트북은 본부 운영을 열면 코트들이 자동으로 나타납니다. 본부 모니터 열기를 눌러 대기실 TV로 옮기고 전체 화면으로 띄우세요.
본부 모니터코트별 지금 경기 · 다음 경기 3개 · 대기 선수 · 다음 부문이 나란히 보입니다.
자동 호출코트가 새 부문을 시작하면 「B코트, ○○부 선수는 준비해 주세요」가 크게 뜨고 소리로 나옵니다. (본부 운영에서 끄거나 직접 호출할 수 있습니다) 소리를 내려면 본부 모니터 화면을 한 번 눌러 주세요.
공지본부 운영 → 공지에서 「아래 띠」 또는 「전체 화면」으로 점심시간·시상식 안내를 띄웁니다.
통합 결과모든 코트의 입상자와 팀 종합 순위를 모아 보여 주고, 엑셀로 저장합니다.
코트 노트북이 꺼지면본부 운영과 모니터에 「○코트 연결 끊김」이 바로 뜹니다. 다시 켜면 자동으로 이어집니다.
코트가 자동으로 안 나타나면: 본부 운영 → 「🔎 지금 다시 찾기」를 누르거나, 코트 노트북 검은 창에 보이는 주소(예: 192.168.0.12:8080)를 「주소로 추가」에 넣으세요.
대회 전에 공유기 하나에 코트 노트북·본부 노트북·심판 휴대폰을 모두 연결해 꼭 한 번 연습해 보세요.

📋접수 명단 → 본부 → 각 코트 (대회 전날)

  1. 본부 노트북을 인터넷에 연결하고 현장 프로그램을 「본부」로 켭니다.
  2. 본부 노트북에서 접수 홈페이지 관리자 화면 → 🖥 현장 노트북 품새·겨루기·격파 앱으로 보내기 → 열린 앱에서 가져오기 → 교체. (태권체조·팀 경연은 품새 앱에 함께 들어갑니다)
  3. 각 앱 대진표 → 🏟 코트 나누기에서 코트 수를 고르고 자동으로 나누기. 코트마다 끝나는 시각이 보이고, 부문 옆 글자로 코트를 바꿀 수 있습니다.
  4. 📡 모든 코트로 보내기 (또는 코트마다 「📡 A코트로 보내기」). 코트 노트북은 같은 와이파이에 「A코트」 등으로 켜져 있어야 합니다.
  5. 각 코트 노트북 운영석에 「📥 본부에서 A코트 명단이 왔습니다」가 뜨면 명단 가져오기 → 미리보기에서 교체.
코트 노트북마다 허가 코드가 들어가 있어야 선수 20명 넘게 들어갑니다. 와이파이가 안 되면 「📥 A코트 명단 엑셀」(품새)이나 공통 명단 엑셀을 USB로 옮겨도 됩니다.

4온라인 명단을 현장으로 가져오기

  1. 인터넷이 되는 곳에서 Claude의 품새 앱 → 대회 설정·백업 → 지금 백업 파일 받기.
  2. 현장 모드 운영석 → 대회 설정·백업 → 백업 파일에서 복구 → 받은 파일 선택 → 복구 실행.
대회가 끝나면 반대로 하면 됩니다: 현장 모드에서 백업 → Claude 앱에서 복구. 온라인에도 결과가 남습니다.

5결과는 어디에 저장되나요?

엑셀·PDF·백업 파일프로그램 폴더의 대회결과 → 날짜 폴더 (운영석 노트북에서 내려받을 때)
대회 데이터 전체프로그램 폴더의 현장모드_데이터 (점수가 들어올 때마다 자동 저장)
노트북이 꺼졌다 켜지면?프로그램만 다시 켜면 명단·점수가 그대로 있습니다. 휴대폰들도 자동으로 다시 연결됩니다.

🔊구령 음성 (인터넷 없이)

  • 현장 모드에서는 노트북 안에 들어 있는 한국어 목소리(예: Microsoft Heami)로 구령이 나옵니다. 「Google」「Online」 목소리는 인터넷이 있어야 나오므로 쓰지 않습니다.
  • 목소리가 없다는 안내가 뜨면: Windows 설정 › 시간 및 언어 › 음성에서 「한국어」 음성을 추가하세요(한 번만, 인터넷 필요).
  • 진행요원 목소리로 바꾸려면 프로그램 폴더의 구령음성 폴더에 준비·시작·바로·쉬어·청승·홍승·차렷·경례.mp3 파일을 넣고 운영석을 새로 고침(F5)하세요.
  • 운영석 「🔊 차렷·경례」 단추로 차렷·경례 구령을 낼 수 있습니다.

🎥영상 판독

  • 코트 노트북에 USB 웹캠을 꽂고, 운영석 오른쪽 아래 「🎥 영상 판독 켜기」를 누릅니다. 카메라 허락 창이 뜨면 「허용」.
  • 작은 화면에 실시간 영상이 보이고, 최근 60초를 노트북 메모리에 계속 담아 둡니다(파일로 쌓이지 않음).
  • 판독 요청이 오면 「⏪ 판독」 → 전체 화면에서 ⏪10초·⏪3초, 한 장씩, 1/2·1/4 느리게 재생으로 확인합니다. 스페이스=재생/멈춤, ←/→=한 장씩, Esc=닫기.
  • 「💾 이 장면 저장」을 누르면 그 장면 앞뒤 5초가 프로그램 폴더의 판독영상 → 날짜 폴더에 영상 파일(.webm)로 저장됩니다.
  • 카메라는 삼각대에 올려 경기장 전체가 보이게 두세요. 카메라가 두 대 이상이면 작은 화면 아래에서 고를 수 있습니다.

↻자동 업데이트

  • 프로그램을 켤 때 한 번, 인터넷이 되면 새 버전이 있는지 확인합니다. 새 버전이 있으면 프로그램 파일만 바꾸고 스스로 다시 켜집니다. 검은 창에 「업데이트 완료」가 보입니다.
  • 대회 중에는 바뀌지 않습니다. 확인은 켤 때만 하고, 인터넷이 없으면(공유기만 있는 대회장) 그냥 지금 버전으로 켜집니다.
  • 명단·점수(현장모드_데이터)와 결과 파일(대회결과)은 그대로 남습니다.
  • 대회 전날, 인터넷이 되는 곳에서 한 번 켜 두면 최신 버전으로 준비됩니다.
  • 끄고 싶으면 프로그램 폴더의 설정.json에 "autoUpdate": "꺼짐"을 넣으세요.

6연결 상태 보는 법

  • 심판 화면 위쪽: 🟢 연결됨 / 🟠 전송 중 · 전송 대기 N건 / 🔴 연결 끊김
  • 끊겨도 채점은 계속하세요. 점수는 휴대폰에 보관했다가 다시 연결되면 자동으로 운영석에 들어갑니다.
  • 운영석 「심판 기기」: 심판별로 접속 중·끊김, 그리고 보관 N건(아직 안 온 점수)이 보입니다. 보관 건수가 있으면 점수 공개 전에 잠깐 기다려 주세요.

7문제가 생기면

증상해결
휴대폰에서 QR을 찍어도 안 열려요① 휴대폰이 같은 공유기 와이파이에 연결됐는지 (모바일 데이터 말고) ② 방화벽_허용.bat을 실행했는지 ③ 휴대폰 와이파이에서 "인터넷 없음" 안내가 나오면 "계속 연결"을 누르세요.
QR 주소가 이상해요 (172.… 등)운영석 대회 설정·백업 → 운영 방식에서 노트북 주소 고르기를 공유기 쪽 주소(보통 192.168.…)로 바꾸세요.
검은 창에 "와이파이에 연결되어 있지 않습니다"노트북을 공유기 와이파이에 연결한 뒤 검은 창을 닫고 프로그램을 다시 켜세요.
노트북이 잠들어요프로그램이 켜져 있는 동안은 잠들지 않게 해 두었습니다. 그래도 충전기는 꼭 꽂아 두세요.
프로그램을 두 번 눌렀어요괜찮습니다. 이미 켜져 있으면 그 화면을 다시 열어 줍니다.
