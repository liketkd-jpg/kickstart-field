# KICKSTART UP 현장 모드

인터넷 없이 공유기 와이파이 하나로 태권도 대회(품새·격파·겨루기·본부)를 운영하는 노트북 프로그램입니다.

- **처음 설치:** [Releases](../../releases/latest)에서 `KICKSTART_Field.zip`을 받아 압축을 풀고 `KICKSTART-field-windows.exe`를 실행합니다.
- **업데이트:** 대회 노트북은 인터넷이 될 때 켜면 최신 릴리스로 자동으로 바뀝니다. 대회 데이터(`현장모드_데이터`, `대회결과`, `판독영상`, `구령음성`)는 그대로 남습니다.
- **새 버전 만들기(관리용):** `server/` 코드를 고친 뒤 `v1.2.3` 같은 태그를 올리면 GitHub Actions가 프로그램을 만들어 릴리스에 붙입니다.
